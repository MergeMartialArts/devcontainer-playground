# Learning Resources

## Documentation & Getting Started

- [Introduction to Dev Containers](https://docs.github.com/en/codespaces/setting-up-your-project-for-codespaces/adding-a-dev-container-configuration/introduction-to-dev-containers) - Learn the fundamentals of dev containers and how to set up your project with GitHub Codespaces.

- [Dev Containers Specification](https://containers.dev/implementors/spec/) - Access the official specification for how dev containers work and their implementation details.

## GitHub Codespaces Personalization

- [Personalizing GitHub Codespaces](https://docs.github.com/en/codespaces/setting-your-user-preferences/personalizing-github-codespaces-for-your-account) - Customize your GitHub Codespaces experience with personal preferences and settings.

## Dev Container Images & Tools

- [Dev Container Images History](https://github.com/devcontainers/images/blob/main/src/universal/history/dev.md) - Review the changelog and version history of official dev container images.

- [Microsoft DevContainers Base Image](https://mcr.microsoft.com/en-us/artifact/mar/devcontainers/base/about) - Explore the Microsoft Container Registry's base dev container image specifications.

- [VS Code DevContainers on Docker Hub](https://hub.docker.com/r/microsoft/vscode-devcontainers) - Find and pull official VS Code dev container images from Docker Hub.

- [Ubuntu Dev Container Configuration](https://github.com/microsoft/vscode-dev-containers/tree/main/containers/ubuntu) - Browse example Ubuntu-based dev container configurations and setup templates.
